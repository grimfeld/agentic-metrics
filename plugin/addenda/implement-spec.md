agentic-metrics addendum to the spec-implementation skill (convention: agentic-metrics:conventions).

A ticket may carry an `estimate: <n><h|d|w>` comment (for example `estimate: 2d`). The estimate is optional: a ticket without one is implemented as normal, without asking for an estimate, waiting for one, or adding one on the human's behalf. An estimate written after work starts is ignored by the metrics, so none is added retroactively.
