agentic-metrics addendum to the PR-writing skill (convention: agentic-metrics:conventions).

When the human stepped in during this work (corrected a direction, fixed something by hand, unblocked an agent, or made a call the agents could not), the PR description ends with one line:

Notable intervention: <one sentence on what the human did and why>

When the work ran without such a step, the line is left out. It is never written as "none". The metrics report quotes this line in case studies.
